# 炫记 2.0

## 项目简介

炫记是面向家教老师与个人学习者的一体化工作学习管理微信小程序，把三件事整合到一起：

- **工作** = 家教教学（课程排课、课堂反馈、作业评价）
- **学习** = 个人成长（学习记录、学习计划、学习目标）
- **任务** = 日常待办（Todo）

通过「今日 / 日历 / 数据 / 我的」四个一级页面形成使用闭环，数据全部保存在本地 Storage。

## 核心模块

- 今日（Daily Dashboard）
- 日历（Planning）
- 数据（Insights）
- 我的（Management Hub）

## 主要功能

- 任务管理（快速添加 / 全部任务 / 优先级 / 截止日期 / 项目 / 标签）
- 学习记录（类型 / 时长 / 内容 / 项目关联）
- 学习计划（阶段计划 + 进度）
- 学习目标（全局目标 / 类型目标 / 计划目标）
- 项目管理（聚合任务 / 学习 / 笔记）
- 笔记（知识记录）
- 时间线（活动回顾）
- 日历安排（课程 / 学习 / 任务 / 项目）
- 教学记录 / 教学历史
- 课堂反馈 / 作业评价
- 数据统计（学习 / 教学 / 任务 / 项目 / 笔记）
- 数据备份与恢复
- 双主题（紫色 / 蓝紫）

## 技术栈

微信小程序原生开发：

- WXML
- WXSS
- JavaScript
- 微信小程序 Storage

项目不依赖云开发、登录或后端服务。
